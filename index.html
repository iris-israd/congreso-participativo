Configuración requerida

Esta aplicación necesita conectarse a tu proyecto de Supabase antes de poder usarse.

1. Abre index.html con un editor de texto y busca la constante SUPABASE_URL y SUPABASE_ANON_KEY cerca del inicio del bloque <script>.

2. Reemplázalas con la URL y la clave anon/public de tu proyecto (Supabase Dashboard → Project Settings → API).

3. Ejecuta el archivo schema.sql incluido en el editor SQL de Supabase (SQL Editor → New query) para crear las tablas y funciones necesarias.

4. Recarga esta página. El usuario inicial es admin / admin123 — cámbialo de inmediato desde el panel de Usuarios.
